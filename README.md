
# Akanksha Dwivedi | Portfolio

A personal portfolio showcasing my projects, technical interests, skills, and journey as a Computer Science and Engineering student.

## About the Portfolio

This portfolio is a multi-page React application designed to present my work, background, and technical interests through an interactive and animation-driven experience.

It brings together my introduction, selected projects, technical skills, education, and contact information in one place.

## Features

- **Home Page:** Introduction, availability status, animated technology marquee, and featured projects.
- **Work Page:** Explore projects through category-based filtering and technology-based search.
- **Project Details:** Individual project pages containing descriptions, technology stacks, source-code links, and previews.
- **About Page:** Personal introduction, technical skills, and educational background.
- **Contact Page:** Direct email and professional profile links.
- **GSAP Animations:** Smooth entrance animations, animated marquee, and interactive project-card hover effects.
- **Responsive Navigation:** Navigation menu adapted for smaller screens.
- **Reusable Components:** Modular React components for maintainability and consistency.

## Featured Projects

The portfolio currently showcases the following projects:

### 1. GitVerse
**Category:** Web Development

An interactive GitHub analytics platform that allows users to explore GitHub profiles, compare developers, analyze repositories, and visualize programming language statistics.

**Technologies:** JavaScript, GitHub API, Chart.js, GSAP, HTML, CSS.

- [GitHub Repository](https://github.com/Akanksha-1708/GitVerse)

### 2. Persistent Streaming AI Chatbot
**Category:** Generative AI

A conversational AI application featuring real-time response streaming and thread-based conversation memory. Built using LangGraph and Streamlit, with Mistral AI for response generation and MemorySaver for conversation persistence.

**Technologies:** Python, LangChain, LangGraph, Mistral AI, Streamlit.

- [GitHub Repository](https://github.com/Akanksha-1708/Agentic-AI-mini-projects)

### 3. SkillSwap
**Category:** Web Development

A peer-to-peer skill exchange platform concept where users can share and learn skills through collaboration rather than monetary transactions. The project explores AI-powered skill matching and knowledge exchange.

**Technologies:** React, Vite, Firebase.

- [GitHub Repository](https://github.com/Akanksha-1708/Skillswap-react)

### 4. Cosmic Guardian AI
**Category:** AI & Data Visualization

An interactive space intelligence platform concept combining Earth visualization, ISS tracking, satellite monitoring, space-weather insights, near-Earth object tracking, and an AI-powered space assistant.

**Technologies:** Next.js, React, TypeScript, Tailwind CSS, Three.js, Space APIs.

- [GitHub Repository](https://github.com/Akanksha-1708/Cosmic-Guardian-AI)

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Akanksha-1708/Portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd Portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Generates the production build |
| `npm run preview` | Previews the production build |
| `npm run lint` | Runs ESLint checks |
